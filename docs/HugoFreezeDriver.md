# HugoFreezeDriver

## 项目简介

HugoFreezeDriver 用于查询和管理希沃磁盘冻结驱动，支持冻结状态查询、冻结/解冻盘符设置、底层驱动信息诊断、配置文件导入导出、驱动事件监控、WPP 日志刷新以及蓝屏触发验证等功能。

程序必须以管理员身份运行，并依赖系统中已安装的对应冻结驱动。无参数运行时进入交互菜单，也可以通过命令行参数执行查询或设置操作。

可以导入 `HugoFreezeFile` 编辑的配置。

## 功能概览

- 启动时强制校验管理员权限；
- 初始化并管理冻结驱动实例，退出时自动清理资源；
- 支持命令行模式和交互式菜单；
- 查询当前磁盘冻结状态，包括盘符状态、配置信息和运行时状态；
- 设置需要冻结或解除冻结的盘符；
- 查询底层驱动详细信息，包括启动统计、初始化结果、穿透统计、质量统计、卷剩余空间、蓝屏记录、IRP 重定向队列统计等；
- 查询线程池 TID，注意该接口会重置驱动重定向队列配置；
- 导出驱动配置到 `VolumeInfo.config`；
- 从配置文件导入并写入驱动，同时覆盖系统配置文件；
- 监控驱动事件通知，包括驱动加载、进程创建、底层穿透、驱动质量、磁盘爆满；
- 刷新驱动 WPP 日志；
- 触发蓝屏，用于验证蓝屏拦截功能；
- 默认记录运行日志到 `HugoFreezeDriver.log`。

## 命令行用法

```text
HugoFreezeDriver.exe [选项]
```

| 选项 | 说明 |
| --- | --- |
| `--query` | 查询当前冻结状态 |
| `--set <盘符>` | 设置冻结目标盘符，例如 `CD` 表示 C 盘和 D 盘，`0` 表示解除所有冻结 |
| `--help`, `-h` | 显示帮助信息 |
| 无参数 | 进入交互式菜单 |

示例：

```bat
HugoFreezeDriver.exe --query
HugoFreezeDriver.exe --set CD
HugoFreezeDriver.exe --set 0
HugoFreezeDriver.exe --help
```

## 日志

程序默认使用 `HugoFreezeDriver.log` 记录运行日志，包括查询、设置、导入导出、错误和危险操作等关键行为。

## 注意事项

- 必须以管理员身份运行；
- 希沃冻结驱动未安装时，程序无法完成初始化；
- 冻结/解冻设置、导入配置等写操作通常需要重启计算机后生效；
