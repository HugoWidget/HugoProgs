# HugoWndRec

## 项目简介

**HugoWndRec** 是一个监视“希沃管家”窗口尺寸的小工具。它以后台线程持续枚举目标窗口，按 **「宽x高」** 记录出现过的每一种窗口尺寸，为每种尺寸自动保存一张窗口截图，并允许用户把某个尺寸加入**拦截列表**——命中拦截列表的窗口会被自动发送 `WM_CLOSE` 关闭，且不再显示。

要开机自启并隐藏控制台窗口，可以使用附带的 `Launcher` ，并指定 `ShowWnd=0` ，使用其他方式单独运行也可。

要结束正在运行的后台进程，再次打开 `HugoWndRec` 然后选择结束进程即可。

## 监视目标

只有同时满足以下条件的窗口才会被处理：

| 条件     | 取值                                     |
| -------- | ---------------------------------------- |
| 窗口标题 | `希沃管家`（完全相等）                   |
| 窗口类名 | `Chrome_WidgetWin_0`（完全相等）         |
| 进程名   | 包含 `SeewoServiceAssistant`（不区分大小写） |

其中进程名由窗口所属 PID 通过 `QueryFullProcessImageNameW` 取得（仅文件名部分），因此 `SeewoServiceAssistant.exe` 等各种变体均可命中。

## 功能特性

- **后台持续扫描**：独立线程每 1000 毫秒枚举一次窗口，扫描线程不阻塞菜单交互。
- **尺寸自动记录**：首次出现的「宽x高」会写入记录文件，并在控制台与日志中提示。
- **自动截图**：每种尺寸自动保存一张 `HugoWndScreenshots/<宽x高>.bmp`（文件已存在时不重复截图）。
- **拦截列表**：加入拦截的尺寸会被视为不需要的窗口，立即关闭并持续拦截。
- **单实例运行**：已有实例在运行时直接退出，避免重复扫描与状态文件互相覆盖。

## 使用方法

### 运行

```cmd
HugoWndRec.exe
```

启动后会打印过滤条件、各文件位置，并直接进入主菜单；后台扫描线程同时开始工作。

例如，要拦截希沃管家的U盘提示窗口，请在 HugoWndRec 运行时插入U盘等待窗口出现，程序会自动检测到窗口，然后在窗口尺寸管理中拦截即可，之后每次提示窗口出现，都会被 HugoWndRec 关闭。

## 工作原理

1. **载入状态**：读取 `HugoWndSeenSizes.txt` 与 `HugoWndBlockedSizes.txt`。
2. **启动扫描线程**：每轮（间隔 1000 毫秒，内部以 100 毫秒为单位可中断睡眠）枚举窗口并逐个处理：
   - 尺寸命中**拦截列表** → `PostMessageW(WM_CLOSE)` 关闭该窗口，记录 `关闭` 日志，不进入后续步骤；
   - 尺寸**首次出现** → 加入记录列表、写回文件、记录 `检测` 日志并在控制台提示；
   - 尺寸**当轮首次遇到且截图文件不存在** → 加入截图队列（同一尺寸每轮只排一张）；
   - 收集为「当前匹配窗口」快照，供主菜单 `[2]` 展示。
3. **执行截图**：在状态锁之外调用 WinUtils 的 `CaptureWindowToBmp`，生成 32 位自顶向下的 BMP。
4. **退出**：在主菜单选择 `0` 后置停止标志，等待扫描线程结束，再保存两个尺寸文件并提示保存结果。

## 文件产物

| 文件 / 目录               | 说明                                                         |
| ------------------------- | ------------------------------------------------------------ |
| `HugoWndSeenSizes.txt`    | 已记录的尺寸，每行一个 `宽x高`，UTF-8 无 BOM，按宽、高数值排序 |
| `HugoWndBlockedSizes.txt` | 拦截列表，格式同上                                           |
| `HugoWndScreenshots\`     | 截图目录，文件名为 `宽x高.bmp`                               |
| `HugoWndRec.log`          | 运行日志，只记录「新尺寸检测」与「关闭窗口」两类事件         |

## 注意事项

- **关闭方式为 `WM_CLOSE`**：由目标程序自行决定是否响应，属于“礼貌关闭”，不保证一定成功（失败时不会记录 `关闭` 日志）。
- **每尺寸仅一张截图**：自动截图只在文件不存在时进行，因此保留的是首个被捕获窗口的画面；需要更新请用 `s<N>`。
- **拦截即时生效**：`b<N>` 会立刻关闭同尺寸窗口；若该尺寸对应的是正常需要的窗口，请谨慎使用，可用 `u<N>` 撤销。
- **状态文件为纯文本**：可直接用文本编辑器查看或编辑（每行 `宽x高`），改动后重新运行即可生效。
