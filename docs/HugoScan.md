# HugoScan

## 项目简介

HugoScan 是基于 C++ 开发的 Windows 平台希沃管家内存扫描工具，核心用于**从希沃管家进程（SeewoCore.exe）的内存中提取管理员密码与锁屏密码**，同时提供通用的内存特征码扫描能力。工具支持命令行与交互式菜单两种操作模式，具备进程自动重连、去重输出、权限诊断与十六进制上下文转储等特性，适用于快速定位和验证希沃密码及自定义内存特征。

## 核心功能

### 密码提取模式

- 目标进程固定为 `SeewoCore.exe`；
- 内置两个特征码：
  - `adminPassword\":\"` —— 管理员密码；
  - `lockStreamPassword\":\"` —— 锁屏密码；
- 仅扫描可写内存区域（`writableOnly`）；
- 命中后提取字符串值，并按**去重**策略输出；
- 进程重启后**保留历史值**，仅输出增量（新增的唯一值）；
- 支持进程自动重连：SeewoCore.exe 退出后自动等待其重新启动并继续扫描。

### 一般内存扫描模式

- 自定义目标进程名或 PID；
- 自定义特征码（支持 HEX / ASCII 混合语法）；
- 命中后输出 **64 字节上下文**（hex + ascii 双栏转储，命中行以 `>>` 标记）；
- **不去重**，每轮命中均输出；
- 目标进程缺失时持续等待（不退出）；
- 输出扫描统计：区域数、块数、读取字节数、失败读取数、命中数、耗时。

### 通用能力

- **权限检测与诊断**：
  - 检测是否以管理员身份运行；
  - 尝试启用 `SeDebugPrivilege` 并报告状态；
  - 打开进程失败时按概率给出原因（未提权 / 特权未启用 / PPL 保护 / PID 瞬时消失）；
- **进程生命周期回调**：Connected / Disconnected / Restarted 事件通知；
- **状态节流输出**：等待、打开失败、扫描中等状态按 10 轮或命中事件节流打印，避免刷屏；
- **优雅退出**：安装 Ctrl+C 处理器，可随时中断扫描循环并输出最终汇总。

## 使用方法

### 前置要求

- 运行环境：Windows；
- 权限建议：**以管理员身份运行**（否则可能无法打开 SeewoCore.exe 等目标进程）；
- 目标进程：密码提取模式需系统中存在 `SeewoCore.exe`（希沃管家安装后运行）；
- 依赖组件：`MemScan` 模块、`WinUtils` 工具库（随源码一同编译）。

### 命令行

```text
HugoScan.exe --extract     提取密码模式 (SeewoCore.exe)
HugoScan.exe --scan        一般内存扫描模式
HugoScan.exe --help, -h    显示帮助
```

- `--extract`：进入密码提取模式，直接开始扫描并等待进程；
- `--scan`：进入一般内存扫描模式，需按提示输入进程名/PID 与特征码；
- `--help` / `-h`：显示帮助信息；
- 未知选项返回 1；
- **无参数运行**则进入交互式菜单。

### 交互式菜单

无参数运行：

```text
=================================================
         希沃管家内存扫描器
=================================================
  1. 提取密码        (SeewoCore.exe: 管理员密码 + 锁屏密码)
  2. 一般内存扫描    (自定义进程 + 特征码, 不去重)
  0. 退出
-------------------------------------------------
  当前权限: 管理员 | SeDebugPrivilege: 已启用
=================================================
请选择 [0-2]:
```

一般内存扫描模式会继续提示输入：

```text
进程名或PID: SeewoCore.exe
特征码 (HEX/ASCII): 48 65 6C 6C 6F
```

### 输出示例

密码提取命中：

```text
[+] 新 管理员密码: "xxxxxxxx"
    地址: 0x0000000012345678
```

一般扫描命中：

```text
--- 命中 @ 0x0000000012345678 ---
>> 0x0000000012345600: 48 65 6C 6C 6F 20 57 6F  72 6C 64 00 00 00 00 00  |Hello World.....|
   0x0000000012345610: ...                                                    |................|
```

## 注意事项

- 内存中的字符串**不保证就是最终运行时有效的密码**，请自行验证；
- 若提示 `ACCESS_DENIED`：
  - 未以管理员运行 —— 右键【以管理员身份运行】；
  - `SeDebugPrivilege` 未启用 —— 管理员下仍失败可能被系统策略禁用；
  - 目标为受保护进程（PPL）—— 普通用户态无法读写，需驱动；
- 密码提取模式采用去重输出，进程重启后仅报告新出现的唯一值；
- 一般扫描模式不去重，命中频繁时输出量可能较大；
- 使用 `Ctrl+C` 可随时中断扫描并查看最终汇总结果。

## 日志

写入程序目录下的 `HugoScan.log`，记录程序启动、模式进入、初始化失败、致命错误与用户退出等关键事件。
