# HugoLaunchTool

## 项目简介

- HugoLaunchTool 是基于 C++ 开发的 Windows 平台希沃（Seewo）进程/服务管理工具，核心用于**快速启动希沃核心服务或终止指定的希沃相关进程**。工具强制要求管理员权限运行，既支持命令行参数操作，也提供**交互式菜单**，适用于便捷管控希沃程序的启停状态。
- 所有操作均会写入日志文件 `HugoLaunchTool.log`，便于问题排查。

## 核心功能

- **希沃服务启动**（`start`）：启动前自动终止 `HugoLaunchTool.exe` 进程以避免冲突，随后尝试启动 `SeewoCoreService` 系统服务；
- **希沃进程监控终止**（`stop`）：启动进程监控，按 1 秒间隔持续检测并强制终止指定希沃进程，按任意键退出监控；该模式通过单实例机制保证同一时间只运行一个实例；
- **希沃进程单次终止**（`kill`）：立即终止一次指定希沃进程，不进入持续监控；
- **交互菜单模式**：不带任何命令行参数启动时，进入中文交互菜单，可在启动服务、监控终止、单次终止、退出之间循环选择；
- **权限强制校验**：启动时自动校验管理员权限，非管理员权限直接退出，确保服务/进程操作具备足够权限；
- **高 DPI 适配**：启用 Per-Monitor DPI Awareness V2，界面在高分屏下显示正常；
- **日志记录**：基于内置 `Logger` 模块，默认输出到 `HugoLaunchTool.log`。

### 目标进程与服务

| 类型             | 名称                                                         |
| ---------------- | ------------------------------------------------------------ |
| 目标服务         | `SeewoCoreService`                                           |
| 需终止的进程     | `SeewoServiceAssistant.exe`、`SeewoCore.exe`、`SeewoAbility.exe`、`SeewoLauncherGuard.exe` |
| 启动前清理的进程 | `HugoLaunchTool.exe`                                         |

## 使用方法

### 前置要求

- 运行环境：Windows 系统；
- 权限要求：**必须以管理员身份运行**；
- 依赖说明：无需额外依赖，编译后的可执行文件可直接运行。

### 命令行操作

| 选项            | 说明                                                   |
| --------------- | ------------------------------------------------------ |
| `-start`        | 启动希沃核心服务（会先终止 `HugoLaunchTool.exe` 进程） |
| `-stop`         | 持续监控并终止希沃进程，**按任意键退出**；单实例运行   |
| `-kill`         | 单次立即终止希沃进程                                   |
| `--help` / `-h` | 显示帮助信息                                           |

示例：

```bat
:: 启动希沃核心服务
HugoLaunchTool.exe -start

:: 持续监控并终止希沃相关进程（按任意键退出）
HugoLaunchTool.exe -stop

:: 单次终止希沃相关进程
HugoLaunchTool.exe -kill

:: 查看帮助
HugoLaunchTool.exe -h
```

### 交互菜单模式

直接运行 `HugoLaunchTool.exe`（不带参数）即进入交互菜单：

```
=== 希沃服务控制工具 ===
1. 启动希沃核心服务
2. 监控并停止希沃进程
3. 单次终止希沃进程
0. 退出程序
请输入选择:
```

输入对应数字后回车执行；执行完毕（除退出外）会暂停等待按键，便于查看结果。

## 注意事项

- `-stop` 参数的进程终止操作是**持续**的：只要程序运行，就按 1 秒间隔持续检测并终止目标进程，直到用户按键退出；
- `-stop` 模式使用单实例机制，请避免重复启动多个监控实例；
- `-start` 会先终止所有 `HugoLaunchTool.exe` 进程，请留意运行中的其它实例；
- 所有操作均需管理员权限，否则程序会直接退出；
- 日志默认写入当前目录下的 `HugoLaunchTool.log`，如遇异常可先行查阅日志。
